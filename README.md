# Reclaim Seoul Wasp Atlas Explorer

`Reclaim Seoul Wasp Atlas Explorer` is a workshop-specific clone of the original `Wasp-Atlas-Explorer`, prepared for Unit 3, Reclaim Seoul: Combinatorial Material Reuse for a Temporal City, at AA Visiting School Seoul 2026.

The app keeps the original Wasp Atlas references intact while reframing the website for the workshop. It reads modular system datasets from the Reclaim Seoul [Reclaimed-Design-Systems](https://github.com/ReclaimSeoul/Reclaimed-Design-Systems) collection and renders interactive assemblies in the browser through `webwaspjs`.

## Workshop context

AA Visiting School Seoul 2026 is organized through the Social Algorithms Research Group and examines what has emerged from Seoul's social, physical, local, and territorial realities after compressed modernization. The programme frames three units around hidden urban structures and operations, the Korean apartment, and reclaimed materials.

Unit 3, Reclaim Seoul, is tutored by Andrea Rossi and Hyo Wook Kim. It explores reclaimed and readily available urban materials as drivers for discrete and combinatorial architectural systems, combining rapid digitization, computer vision, Wasp aggregation logic, structural feedback, and augmented-reality-guided assembly.
